# Мобилити — трекер аренды байков

Веб-приложение для курьеров (аренда байков по Flex-тарифу, заявки на обслуживание, история) и панель управления владельца.

## Запуск

Нужен Node.js 22.13+ (встроенный `node:sqlite`, внешних зависимостей нет).

```bash
npm start            # http://localhost:3000
npm run dev          # то же, с перезапуском при изменении серверного кода
PORT=8080 npm start
ADMIN_EMAIL=owner@example.com npm start
```

Запуск на сервере с HTTPS, автозапуском и резервными копиями — в [deploy/README.md](deploy/README.md).

База создаётся автоматически в `data/mobility.db`; байки добавляются при первом запуске.

## Адреса

| Адрес | Что открывается |
| --- | --- |
| `/app` | приложение курьера (`/app/bikes`, `/app/history`, `/app/settings`, …) |
| `/admin` | панель управления (`/admin/bikes`, `/admin/repairs`, `/admin/rentals`, `/admin/couriers`, `/admin/settings`) |
| `/` | перенаправляет на `/app` |

Панель открывается только владельцу — аккаунту с почтой `ADMIN_EMAIL`. Остальным показывается вход администратора.
Владелец может пользоваться и приложением курьера.

Старые ссылки вида `/app#/history` автоматически переводятся на `/app/history`.

## Структура

```
deploy/              файлы для сервера: systemd, Caddy, бэкап, обновление

server/
  index.js            HTTP-сервер: /api/* → маршруты, остальное → статика
  config.js           настройки (порт, почта владельца, лимиты)
  db.js               SQLite: схема, миграции, начальные байки, настройки
  lib/
    http.js           ответы, чтение JSON, проверка данных
    auth.js           пароли, сессии, текущий пользователь
    router.js         маршрутизатор API (public / admin)
    static.js         файлы из public/, входы /app и /admin, кэш
  services/fleet.js   байки с арендами и заявками, активная аренда
  routes/
    auth.js           регистрация, вход, выход, /api/config
    me.js             профиль и смена пароля
    courier.js        байки, аренда, история, заявки на обслуживание
    admin.js          всё для панели

public/
  app.html, admin.html          точки входа
  splash.html                   анимированная заставка
  manifest.webmanifest          установка на экран «Домой»
  css/base.css                  общие стили (кнопки, поля, окна, уведомления, лоадер)
  css/app.css, css/admin.css    стили приложения и панели
  js/core/                      общее: маршрутизатор, запросы, окна, иконки, форматирование
  js/app/                       приложение курьера: main.js + screens/*
  js/admin/                     панель: main.js, shell.js + screens/*
  assets/bikes/, assets/brand/  фото байков и логотипы
  icons/                        иконки для iPhone и Android

```

## Как добавить

- **Экран в приложение курьера** — файл в `public/js/app/screens/`, строка в списке `routes` в `public/js/app/main.js`.
- **Раздел в панель** — файл в `public/js/admin/screens/`, строка в `routes` в `public/js/admin/main.js` и пункт в `NAV` в `public/js/admin/shell.js`.
- **Метод API** — `route(...)` в нужном файле `server/routes/`; новая группа — новый файл и строка `require` в `server/index.js`.
- **Байк** — запись в таблице `bikes` (фото кладётся в `public/assets/bikes/`, в поле `image` — имя файла).

## Что умеет

- **Курьер:** вход и регистрация (владелец может закрыть регистрацию), список байков, аренда свайпом с таймером, звонок в поддержку, заявки на обслуживание, ввод заказов на калькуляторе (сумма = ставка Flex × заказы), отчёт, история за 30 дней, настройки профиля.
- **Владелец:** обзор парка и выручки, байки (добавление с фото, базовый тариф, доступность: доступен / недоступен / скрыт), заявки на обслуживание, аренды (статусы оплаты, правка заказов, удаление), курьеры (создание, фото, пароль, блокировка, рейтинг 1–10, личные цены и скрытие байков для конкретного курьера), открытие и закрытие регистрации.
